# assets/ — ニュースレターに差し込む写真

このフォルダに写真を置くと、`tools/build_pdf.py` が本文の写真枠を実際の画像に差し替えます。

## ファイル名

写真枠の番号をそのままファイル名にします。拡張子は `.jpg` / `.jpeg` / `.png` / `.webp`。

| ファイル名 | 差し込まれる場所 |
|---|---|
| `01.jpg` | 163件 稼働式典の大統領 |
| `02.jpg` | 永遠の友好条約 署名式 |
| `03.jpg` | 両大統領の新タシュケント視察 |
| `05.jpg` | スタジアム建設現場 |
| `06.jpg` | 空港の完成イメージ／予定地 |
| `07.jpg` | 独立記念行事／市街全景 |
| `08.jpg` | 金融フォーラム会場 |

置かなかった番号は、点線の空き枠のまま出力されます。差し替えは番号単位で、いつでも追加できます。

## 出力される見た目

- 幅は本文いっぱい、高さは最大68mmで切り抜き（`object-fit: cover`）
- 写真の下に本文のキャプションが入る
- **社内校正版のみ** キャプションの下に出典（入手先）が入る。配布版には出典行は入りません

## 手順

```bash
# 1. assets/ に画像を置く
# 2. 印刷用HTMLを生成
python3 tools/build_pdf.py
# 3. PDF化
chromium --headless=new --no-pdf-header-footer --print-to-pdf=out.pdf file://$PWD/print_dist.html
```

## 推奨

- 長辺2000px以上（A4印刷で粗くならない目安）
- 横位置。縦位置の写真は上下が大きく切れます
