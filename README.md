# naruトレ（naru-tore v2）

パーソナルトレーナー **naru** が監修する、自宅トレーニングアプリです。
「家でも筋トレできるように」「初心者から上級者まで自分に合った強度で」
「多くの人に運動習慣をつけてもらう」ことを目的にしています。

- 登録不要。データはすべて利用者の端末（localStorage）にのみ保存されます
- 器具なしでも4週間のプランが成立します
- スマホのホーム画面に追加して、アプリのように使えます（PWA）

## 開発

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # 本番ビルド
npm run start      # 本番サーバー
npm run typecheck  # 型チェック
```

Next.js 16（App Router）/ React 19 / TypeScript / Tailwind CSS v4。
外部APIやデータベースは使っていないので、Vercel にそのままデプロイできます。

## 画面構成

| ルート | 内容 |
| --- | --- |
| `/` | ホーム。今日のトレーニング、週の進捗、4週間プラン |
| `/onboarding` | 9ステップの初期設定（性別・年齢・部位・目標・レベル・強度・ペース・器具・体格） |
| `/workout/[id]/preview` | ワークアウトの内容確認（セットごとの種目リスト） |
| `/workout/[id]` | 実行画面。タイマー・休憩・フォームのポイント・音と振動 |
| `/workout/[id]/complete` | 完了画面。体感（RPE）から次回の強度を自動調整 |
| `/library` ・ `/library/[id]` | 種目一覧と種目詳細（ポイント／よくあるミス／呼吸） |
| `/progress` | 連続日数・消費カロリー・2週間の推移・体重グラフ・履歴 |
| `/settings` | 目標／強度／ペース／部位／器具の変更、データ削除 |

## naru本人のお手本動画を追加する

種目データ（`src/lib/exercises.ts`）の `video` フィールドを埋めるだけで、
**実行画面と種目詳細の両方に自動で表示されます**。アプリ側の改修は不要です。

1. 動画を `public/videos/{種目id}.mp4` に置く（ループ再生・音声なし前提。5〜10秒程度の短いクリップが最適）
2. サムネイル用の静止画を `public/videos/{種目id}.jpg` に置く（任意）
3. `src/lib/exercises.ts` の該当種目を書き換える

```ts
{
  id: "squat",
  name: "スクワット",
  // …
  video: {
    src: "/videos/squat.mp4",
    poster: "/videos/squat.jpg",
    caption: "naru / 正面アングル",   // 任意
  },
},
```

`video: null` の種目は、部位をハイライトしたシルエットと
「naruの動画は準備中」というラベルが表示されます。
撮影済みの本数は `/library` の画面上部（「お手本動画 0/49 本」）で確認できます。

> 動画は 720p 程度・数百KB〜数MBに圧縮してください。
> 本数が増えて `public/` が重くなってきたら、`src` を外部の配信URLに変えるだけで移行できます。

## 種目を追加する

`src/lib/exercises.ts` の `EXERCISES` 配列に1件足すだけです。
追加した種目は自動的にプラン生成の候補になり、`/library` にも並びます。

```ts
{
  id: "reverse-lunge",          // 一意なID（動画ファイル名にも使う）
  name: "リバースランジ",
  nameEn: "Reverse Lunge",
  parts: ["legs", "glutes"],    // 部位。プランの「◯◯の日」に選ばれる基準
  equipment: ["none"],          // none / chair / dumbbell / band
  difficulty: 2,                // 1=やさしい 2=ふつう 3=きつい
  measure: "reps",              // "time"（秒）か "reps"（回数）
  phase: "main",                // warmup / main / cooldown
  reps: 12,
  seconds: 45,                  // 目安時間（カロリー計算にも使用）
  met: 5.5,                     // METs。消費カロリー計算に使う
  unilateral: true,             // 左右交互に行う種目なら true
  cues: ["…"],                  // フォームのポイント
  mistakes: ["…"],              // よくあるミス
  breathing: "…",
  video: null,
}
```

## プラン生成の考え方（`src/lib/plan.ts`）

1. **部位のローテーション** — 選んだターゲット部位と目標から、日ごとの狙う部位を決めます
   （減量なら有酸素を多め、増量なら部位を分割、健康維持は全身をまんべんなく）
2. **種目の選定** — その部位の種目を最優先で選びます。
   種目が3つに満たない部位のときだけ、他部位で補います
3. **セット構成** — 1セット3〜6種目にしぼり、**同じ種目をセットで繰り返す**構成にします。
   セット数は「指定した1回あたりの時間」から逆算するので、
   10分/15分/20分/30分のどれを選んでも所要時間がだいたい合います
4. **漸進性過負荷** — 週が進むごとに秒数・回数が約8%ずつ増えます
5. **消費カロリー** — `METs × 3.5 × 体重(kg) ÷ 200` で算出。体重未入力時は標準値を使います

完了画面で「余裕だった／かなりきつかった」を選ぶと強度が1段階変わり、
プランがその場で作り直されます。

## データの保存

`localStorage` のキー `naru-tore:v2` に、プロフィール・プラン・記録・体重・設定を保存します。
サーバーには何も送信していません。マイページの「データをすべて削除」で消去できます。
