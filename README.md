# Tobidai Cockpit — 株式会社翔び台 社内コックピット

社内のプロジェクト進捗・営業数字・求職者進捗を「1発でわかる」状態にする社内システムです。
設計の詳細は [docs/DESIGN.md](docs/DESIGN.md) を参照してください。

## 機能(下部5タブ)

| タブ | 内容 |
|---|---|
| 今日の経営 | 本日/月内の成約・目標達成率・売上見込み・拠点別実績・求職者パイプライン・プロジェクト進捗・Slackハイライト |
| AIに聞く | チャットで営業数字や進捗を質問すると即答(例:「今日の成約は?」「遅れているプロジェクトは?」) |
| 届ける | 共有したい情報を入力すると、AIが最適な宛先メンバーとSlackチャンネルを提案して配信 |
| 面談AI | 面談・商談の文字起こしから議事録/インサイト/ネクストアクション/シート更新案/フォローメールを一括生成 |
| 提案書 | 求職者の希望条件から企業向け推薦状をA4風プレビューで自動生成 |

ロール切替(経営ビュー/現場ビュー)に対応。スマホ中心のモバイルファーストUIです。

## 起動方法

```bash
npm install
npm run dev       # 開発: http://localhost:3000
npm run build && npm run start   # 本番ビルド
```

## AI・データ連携

- `DATA_MODE` 未設定(既定値)では**デモデータ**(実行日基準で自動生成)で全機能が動作します。`ANTHROPIC_API_KEY` を設定すると AI 応答が Claude API による生成に切り替わります(未設定でもルールベースで動作)。
- `DATA_MODE=live` にすると、Google スプレッドシート / Slack との実連携(`src/lib/adapters/`)に切り替わります。接続・認証に失敗した場合は自動でデモデータへフォールバックし、アプリは落ちません。
- 環境変数の一覧は `.env.example`、セットアップ手順は `docs/SETUP.md`、スプレッドシートのタブ・列仕様は `docs/SHEET_TEMPLATE.md` を参照してください。設計の詳細は docs/DESIGN.md §6 を参照。
