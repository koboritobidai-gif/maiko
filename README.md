# ジャパンプラザ 販売進捗ダッシュボード

ウズベキスタンの物件「ジャパンプラザ」の販売進捗を、**日本語で**わかりやすく確認するためのダッシュボードです。
データ元は uysot CRM（`app.uysot.uz` / API: `api.service.app.uysot.uz`）で、ブラウザから直接 API を呼び出して表示します。

- 本番 URL: https://maiko-self.vercel.app
- 技術構成: Vite + React + TypeScript + Recharts（静的 SPA、Vercel デプロイ）

---

## 表示する指標

### マーケティング
- **使った金額（広告費）** — 流入経路別に集計した広告費の合計
- **リスト数（獲得数）** — 期間内に獲得したリード（見込み客）の数
- **リスト単価（CPL）** — 広告費 ÷ リスト数
- **流入経路数**

### 営業
- **来店数** — パイプラインの該当段階の件数
- **契約数**
- **成約率** — 契約数 ÷ リスト数
- **平均リードタイム**
- **案件ごとの状況** — パイプライン段階別の件数（ファネル）
- **流入経路** — リスト数の内訳（円グラフ＋明細表）

### 売上
- **トータル売上（期間内）**
- **月平均売上**
- **次月以降の売上見込み** — 入金予定ベース
- **月次グラフ** — 売上（棒）＋累計（線）、リスト数／来店数／契約数

すべて **物件・パイプライン・期間（3/6/12ヶ月）** で絞り込めます。

## ログイン方法

ダッシュボードは uysot のアカウントで認証します。2 通りの方法があります。

1. **ログイン（推奨）** — uysot のユーザー名・パスワードを入力。
   - uysot のログインは Google reCAPTCHA で保護されています。この Vercel ドメインが
     reCAPTCHA のサイトキーに登録されていない場合、直接ログインが失敗することがあります。
     その場合は下記「トークン」方式をご利用ください。
2. **トークン** — 既に `app.uysot.uz` にログイン済みのブラウザから、アクセストークンを貼り付け。
   1. 別タブで `app.uysot.uz` にログイン
   2. `F12`（開発者ツール）→ Console
   3. `localStorage.getItem('token')` を実行し、表示された文字列をコピー
   4. ダッシュボードの「トークン」タブに貼り付け

> uysot 側の CORS 設定で `https://maiko-self.vercel.app` が許可されている（credentials 込み）ことを
> 確認済みのため、ブラウザから直接 API を呼び出せます。バックエンドサーバーは不要です。

## データが合わないとき（接続診断）

分析系 API（`plan-fact-pipe` / `contract/filter` など）はアカウントごとにレスポンス形状が
異なる場合があります。本アプリはフィールド名を柔軟に解釈しますが、値が実際と合わない場合は
画面下部の **「接続診断」** を開いてください。

- 各 API の成功／失敗と HTTP ステータスを一覧表示
- 「生データ」ボタンで実際の JSON レスポンスを確認可能

この生データを見れば、どのフィールドを拾うべきか（マッピング）を調整できます。
また「来店」「契約」に対応するパイプライン段階は、フィルター欄のドロップダウンで
自由に対応付けできます（選択はブラウザに保存されます）。

## 主に利用している uysot API

| 用途 | エンドポイント |
|------|----------------|
| 物件一覧 | `GET /v1/building/compact` |
| パイプライン一覧 | `GET /v1/statistics/plan-fact-pipe/pipe` |
| ファネル（顧客フロー） | `POST /v1/statistics/customer-flow/v2` |
| 流入経路・費用 | `POST /v1/statistics/plan-fact-pipe` |
| 契約・売上 | `POST /v1/contract/filter` |
| 入金予定（見込み） | `POST /v1/contract/payment/filter/sum` |

認証は `Authorization: Bearer <accessToken>` ヘッダーで行います。
