# NARU FIT DAILY

パーソナルトレーナー **NARU（杉田 成美）** の、自宅／ジム向けトレーニングアプリです。
2週間で1クール・14日分のメニューが、休む日まで組んであります。

## このリポジトリの中身

| | 中身 | 用途 |
| --- | --- | --- |
| **`index.html`** | 単体で動くHTML 1ファイル（本体） | これが公開するアプリ |
| `videos/` | NARU の実演動画 47本（mp4／ポスター画像／サムネイル） | `index.html` から読み込む |
| `fonts/` | 欧文フォント Saira（可変フォント・latin サブセット 2ファイル） | ロゴに合わせた書体。同梱なのでオフラインでも崩れない |
| `img/` | ロゴ画像とアプリアイコン | LP・申し込み画面・ホーム画面のタイル |
| `legacy/` | 旧版（Next.js 製・v2.0.0 の試作） | 使っていません。素材を見返すために残してあるだけ |

外部ライブラリもビルドも使っていません。`index.html` をダブルクリックすれば
そのまま開きますし、静的ホスティングに置けばそのまま動きます。

## 公開のしかた（Cloudflare Pages）

Cloudflare Pages でこのリポジトリをつないで、

- **フレームワークプリセット**: なし（None）
- **ビルドコマンド**: 空のまま
- **出力ディレクトリ**: `/`（リポジトリのルート）

とすれば、`index.html` がそのままトップページとして公開されます。

> `legacy/` に `package.json` を移してあるのは、Cloudflare が旧版を
> Next.js のサイトと誤認してビルドしに行かないようにするためです。
> ルートに戻すと今のアプリが公開されなくなるので、動かさないでください。

Vercel の無料プラン（Hobby）は**商用利用が禁止**されているので使えません。
Cloudflare Pages の無料枠は、静的サイトの転送量が無制限・ビルド月500回まで・
1ファイル25MiB までで、このアプリ（180ファイル／52MB／最大3.3MB）は収まります。

# アプリの構成

## 3つのレベル

| | 対象 | 日数 | 状態 |
| --- | --- | --- | --- |
| **Fit 1** | 初級者・自宅／自重 | 14日 | 公開中 |
| **Fit 2** | 中級者・自宅ダンベル／ジム | — | **準備中**（メニュー待ち） |
| **Fit 3** | アスリートレベル・ジム | 7日 | 公開中 |

その日の調子でレベルを切り替えられます。記録は共通で残ります。
メニューが入っていないレベルは自動で「準備中」になり、選べません
（`PROGRAM.fit2` に中身を入れた時点で自動的に選べるようになります）。

## 14日サイクル

`CYCLE = 14`。開始日から数えて何日目かを出し、`PROGRAM[レベル]` の
その日のメニューを表示します。Fit 3 のように7日しかないレベルは、
8日目以降は1日目から繰り返します。

休んだ日は「今日は休む（休養日と振り替える）」で、休養日と交換できます
（1クールにつき最大2回まで）。

## 画面

- **LP** — ロゴ・キャッチコピー・Start
- **申し込み画面（ゲート）** — 内容の説明・価格・Stripe への導線・合言葉の入力
- **診断** — 目的とレベルの2問。終わるとホームへ
- **ホーム** — STREAK・今日のDAY・今週の曜日ストリップ・NARU のワンポイント動画
- **今日（TRAIN）** — その日のメニュー全体。種目をタップでフォーム解説
- **実行画面** — チェックリスト式／1種目ずつのタイマー式、どちらでも
- **記録（LOG）** — 直近4週のカレンダーと履歴
- **設定** — レベル変更・特商法/プライバシー/利用規約

## 種目データ

`EX` に **115種目**。うち **47種目**に NARU の実演動画が入っています。

```js
"air-squat":{en:"Air Squat", ja:"エアスクワット",
  video:{src:"videos/air-squat.mp4", poster:"videos/air-squat.jpg"},
  cues:[...], miss:[...], breath:"..."},
```

動画を足すときは `videos/` に `<種目id>.mp4` と `<種目id>.jpg` を置いて、
その種目に `video:` を書き足すだけです。
動画が無い種目は、詳細を開いても動画枠が出ないだけで、他はふつうに使えます。

## メニューの編集

`PROGRAM.fit1` / `PROGRAM.fit3` が1日1オブジェクトの配列です。

```js
{t:"Squat & Push",                       // 英語のDAY名（見出しに出ます）
 ja:"スクワット基礎構築（プッシュ＆スクワット）",
 cardio:CARDIO,                           // 有酸素
 parts:[{k:"TRAINING", r:4,               // r = 周回数
         note:"目標それぞれ、4周しよう！",
         items:[P("air-squat","10 rep"), ...]}]}
```

`P("種目id","処方")` の処方は文字列で、タイマーが自動で読み取ります
（`30 sec` → 30秒カウントダウン、`10 rep × 3 set` → 3セットに展開）。

## 合言葉と自動解除

`ACCESS.codes` の合言葉を入れるとアプリが開きます。
Stripe の決済後の戻り先を `…/?k=合言葉` にしておけば、
**お客さんが合言葉を入力しなくても自動で解除されます**
（解除後、URL からは `k` が消えます）。手入力も引き続き使えます。

## メールアドレスでのログイン（`functions/`）

お客さんは、お申し込みに使ったメールアドレスを入れるだけで開けます。
パスワードを配る必要はありません。

```
メールアドレスを入力
  → /api/unlock（Cloudflare Pages Functions）
  → Stripe に「この人の課金は生きているか」を照会
  → 生きていれば 7日ぶんの有効期限を返す
```

7日たつと、アプリを開いたときに裏でもう一度確認します。
解約されていればそこで開けなくなり、確認できなかったとき
（圏外・サーバー不調）は何もせず開いたままにします。
払っているお客さんを締め出さないためです。

### Cloudflare 側で必要な設定

| 種類 | 名前 | 中身 |
| --- | --- | --- |
| 変数とシークレット | `STRIPE_KEY` | Stripe の制限付きキー（Customers / Subscriptions の**読み取りのみ**） |
| バインディング（KV） | `LOGINS` | ログインの記録用。無くても動きます（記録が残らないだけ） |

`STRIPE_KEY` が無い場合、`/api/unlock` はエラーを返し、
アプリは自動で「パスワードで入る」欄を出します。**サイトは壊れません。**

### ログインの記録

KV の `naru-logins` に、1アドレスにつき1件、直近10回ぶんが残ります。

```json
{ "n": 12, "first": "...", "last": "...",
  "hits": [{ "t": "2026-11-10T…", "co": "JP", "ci": "Osaka",
             "d": "iOS", "ip": "a1b2c3d4" }] }
```

IPアドレスそのものは保存していません（ハッシュの先頭だけ）。
同じアドレスがいくつもの国や端末から開かれていれば、ここで分かります。
Cloudflare のダッシュボード（ストレージとデータベース → KV）から見られます。

### パスワード（控え）

`ACCESS.codes` のパスワードも残してあります。申し込み画面では
「うまくいかないときは」の下に隠れていて、メールで入れない人の
逃げ道として使います。

## データの保存

`localStorage` のキー `naru-tore-v3` に、診断結果・記録・チェック状態・
合言葉を保存します。**サーバーには何も送信していません。**
設定画面から消せます。

## 切り替えスイッチ

ファイル冒頭の定数で、未完成の機能を隠しています。

```js
const SHOW_LANG       = false;  // 英語版の言語切り替え（中身は実装済み・naru の確認待ち）
const SHOW_VIDEO_LIST = false;  // 動画の一覧画面
```

`true` にすればそのまま出ます。

# 旧版（`legacy/`）── 使っていません

参考アプリに寄せて作った、別デザインの試作（Next.js）です。
本体とはデザインも構成も違うため使っていませんが、
種目のフォーム解説データやタイマー・GPS記録の実装を見返せるよう残しています。

```bash
cd legacy && npm install && npm run dev
```
