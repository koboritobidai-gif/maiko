# naruトレ

パーソナルトレーナー **NARU** の自宅／ジム向けトレーニングアプリです。

このリポジトリには2つのものが入っています。

| | 中身 | 用途 |
| --- | --- | --- |
| **`naru-tore-v3.html`** | 単体で動くHTML 1ファイル（本体） | ダブルクリックで開く／そのままデプロイできる |
| `src/` ほか | Next.js版（別デザインの試作） | 素材置き場。種目データなどを流用するために残しています |

---

# naru-tore-v3.html（本体）

既存アプリ（`naru-tore-v2_2.html`）の見た目・構成をそのままに、
使いづらかったところを直して機能を足したものです。
**外部ライブラリなし・ビルド不要**の1ファイルなので、
ダブルクリックで開けますし、Vercel等にそのまま置けます。

## 引き継いだもの（変えていません）

- ベージュ × オリーブ × チャコールの配色、オレンジのCTA、英日併記のトーン
- LP（今日の一歩を、ここから。／ABOUT PERSONAL TRAINING）
- HOME の構成：STREAK バッジ・DAY n カード・Coaching by NARU・Today's Training →
- **PART 1 WARM UP → PART 2 STRENGTH → PART 3 FUNCTIONAL** のプログラム構成
- チェックリスト式の実行画面（できた種目をタップしてチェック → Complete Today）
- 🎉 Training Complete! / N DAY STREAK / View Progress のモーダル
- LOG の LAST 4 WEEKS カレンダーと RECENT SESSIONS
- HOME / TRAIN / LOG の3タブ
- DAY 1 の中身（Deadlift Day）は既存とまったく同じ処方です

## 足したもの

1. **種目をタップするとフォーム解説が開く** — ポイント／よくあるミス／呼吸を全62種目に収録
2. **タイマーで進めるモード** — チェックリストと選べます。セット・ラウンド・休憩・次の種目を自動で進行
3. **強度を Easy / Normal / Hard の3段階に** — 初心者の入口を用意（既存は Normal / Hard の2つ）
4. **12日分のプログラム** — ジム6日・自宅6日。DAY が進むと内容が変わり、次の予定も表示されます
5. **完了後に体感を聞いて次回の強度に反映** — 「楽だった／ちょうどよかった／きつかった」
6. **設定画面** — 目的・強度・場所・週の回数を、**記録を消さずに**変更できます
   （既存は「診断をやり直す（データ消去）」しかありませんでした）
7. **PART 4 COOL DOWN** — 各日にクールダウンを追加
8. HOME に今週の実施状況（曜日ストリップ）を追加

## NARU の実演動画を入れる

HTML内の `EX` の該当種目の `video` を差し替えるだけで、
**種目詳細・ホーム・タイマー画面に自動で表示されます。**

```js
"deadlift":{en:"Deadlift", ja:"デッドリフト",
  video:{src:"videos/deadlift.mp4", poster:"videos/deadlift.jpg"},
  cues:[...], miss:[...], breath:"..."},
```

1. HTMLと同じ場所に `videos/` フォルダをつくる
2. `videos/deadlift.mp4`（と静止画 `deadlift.jpg`）を置く
3. 上のように `video:` を書き換える

`video:null` の間は「準備中」ラベル付きのプレースホルダーが出ます。
現在の収録本数は設定画面で確認できます。

ホームの「NARU のワンポイント動画」枠を埋めるときは、`videoBlock(null)` の分岐に
同じ形で動画を指定してください。

## メニューを編集する

- **種目を足す** — `EX` に1件追加（`en` / `ja` / `cues` / `miss` / `breath` / `video`）
- **日のメニューを変える** — `DAYS.gym` / `DAYS.home` を編集。
  `I("種目id","Easyの処方","Normalの処方","Hardの処方", 星印?)` の形式です。
  処方に `"—"` を入れるとその強度では非表示になります（例：Hard では膝つき腕立てを出さない）
- **目的ごとの並び** — `GOAL_ORDER` で、目的別に何日目にどのメニューを出すかを決めています

タイマーは処方の文字列から自動で秒数・セット数を読み取ります
（`40 sec` → 40秒カウントダウン、`12 rep × 3 set` → 3セット分に展開、
回数種目は「次へ」をタップで進む）。

## データの保存

`localStorage` のキー `naru-tore-v3` に、診断結果・記録・チェック状態を保存します。
サーバーには何も送信していません。設定画面の「診断をやり直す（データ消去）」で消せます。

# Next.js版（`src/`）

参考アプリ（青いデザインのフィットネスアプリ）に寄せて作った別デザインの試作です。
本体とはデザイン・構成が異なるため現在は使っていませんが、
**種目のフォーム解説データ（71種目）やタイマー・GPS記録の実装を流用できる**ので残しています。

```bash
npm install
npm run dev   # http://localhost:3000
npm run build
```

収録内容：4週間プランの自動生成、テーマ別ワークアウト15プログラム、
ジム種目22種目、ウォーキング／ランニングのGPS記録、記録画面（毎日／カレンダー／データ）。
詳細は `src/lib/plan.ts`・`src/lib/programs.ts` を参照してください。
