# maiko

タシュケント／新タシュケントの物件オーナー向け「月次ニュースレター」の設計・テンプレート一式。

現地に来られていないオーナー様へ、**街全体のニュースを資産価値の視点に翻訳して**毎月お届けするための資料です。

## 中身

| ファイル | 用途 |
|---|---|
| `docs/newsletter-2026-08.html` | **創刊号（2026年8月号）の実物**。実際のニュースで組んだ完成形 |
| `templates/newsletter-template.md` | 毎号のひな形。構成・記事の書き方・定点観測先 |
| `docs/news-sources.md` | 情報源リストと、写真の権利処理・制作フロー |
| `docs/content-checklist.md` | オーナーの不安の種類別・掲載項目チェックリスト |
| `docs/photo-shotlist.md` | 現地撮影のショットリストと定点観測のルール |
| `templates/monthly-report-template.md` | 個別物件の工事進捗を報告する場合のひな形（ニュースレターとは別用途） |
| `docs/report-design.html` | 上記のビジュアル設計書 |

## ニュースレターの基本形

- 本文3〜4ページ／読了6分／写真8〜11点
- 構成：今月の3行 → 数字ストリップ → 大統領の動き → インフラ → 街づくり → マーケット → 制度・日本
- 各記事は「事実 → **What this means for owners（オーナー様にとっての意味）**」の2段構え

## 毎号のルール

1. 構成・順番・指標を固定する（比較できることが安心の正体）
2. 数字には必ず出典と日付を添える
3. ニュースは必ず「オーナー様にとっての意味」まで翻訳する
4. 良い話だけにしない
5. 利回り・値上がりを断定しない。免責事項を巻末に固定掲載する
6. 写真の権利処理を必ず確認する
