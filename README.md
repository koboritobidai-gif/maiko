# maiko

新タシュケント／タシュケントの物件オーナー向け「月次レポート」の設計・テンプレート一式。

## 中身

| ファイル | 用途 |
|---|---|
| `templates/monthly-report-template.md` | 毎月コピーして数字と写真を差し込む、本文4ページ分のひな形 |
| `docs/content-checklist.md` | 「買った人が安心する／参考になる」掲載項目のチェックリスト（不安の種類別・優先度つき） |
| `docs/photo-shotlist.md` | 現地撮影のショットリストと定点観測のルール |
| `docs/report-design.html` | 上記をまとめたビジュアル設計書（ブラウザで閲覧） |

## 基本形

- 本文4ページ（P1 サマリー／P2 工事進捗・写真／P3 マーケット・周辺環境／P4 オーナー実務・Q&A）
- 写真7〜10点（定点観測4点＋工程3〜5点）
- 毎月1回、月初5営業日以内に発行

## 毎号のルール

1. 構成・順番・指標は毎号固定する（比較できることが安心につながる）
2. 数字には必ず出典を添える
3. 悪い情報を毎号1つ以上載せる
4. 利回り・値上がりを断定しない。免責事項を巻末に固定掲載する
