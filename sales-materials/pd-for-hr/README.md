# 翔び台 営業資料 ── PD for HR 追加ページ（P10〜P12）

既存の営業資料「翔び台サービス紹介資料（9ページ）」の末尾に、
分割払いサービス **PD for HR（株式会社PROTOCOL）** を紹介する 3 ページを追加したもの。

| ファイル | 内容 |
|---|---|
| `翔び台_サービス紹介資料_PDforHR追加.pptx` | 完成版（全12ページ） |
| `build/slide10-12.png` | 追加した3ページの画像（1920×1080） |
| `src/` | 追加ページの制作ソース（HTML/CSS） |

## 追加ページの構成

- **P10 THE ISSUE** ── 「一括払い」が採用の意思決定を止めている（企業規模別の課題／失注の流れ）
- **P11 NEW OPTION** ── 採用を「一括払い」から「月額」へ（導入前後の比較・キャッシュフロー設計）
- **P12 SCHEME & MERIT** ── スキーム、未回収リスク、返金制度、導入5ステップ、期間限定条件

## 掲載している数値の出典

すべて PD for HR サービス紹介資料（260530版）に基づく。

- 紹介料 210万円＝年収600万円・紹介料35％の場合
- 月額 17.5万円（2ヶ月目以降）／初月は保証料＋17.5万円
- シミュレーション例：紹介料 2,100,000円・保証料13％ → 初月合計 322,875円、2〜12ヶ月 175,000円／月
- 早期退職時の返金率：30日以内 80％／60日以内 50％／90日以内 20％
- 期間限定で加盟金・月額利用料が無料（通常：加盟金30万円／月額5万円）

## ページ番号について

既存の P1〜P9 はページ番号「N / 9」が画像に焼き込まれており、
背景の斜め装飾と重なっているため後から書き換えられない。
追加ページは「N / 12」で表記している。既存ページも揃える場合は、
元データ（PowerPoint / Canva 等）側でページ番号を修正する必要がある。

## 追加ページの作り方（再生成手順）

デザインは既存ページから抽出した配色・ロゴ・フッターを使って HTML/CSS で再現している。

```bash
cd src
./render.sh s10.html s11.html s12.html   # → out_s10.png / out_s11.png / out_s12.png（1920×1080）
```

- 描画は Chromium のヘッドレススクリーンショット。ヘッドレスのビューポートは
  `--window-size` より 87px 低くなるため、`render.sh` は 1920×1167 を指定している。
- 日本語フォントは Noto Sans CJK JP を使用（`apt-get install -y fonts-noto-cjk`）。
- `src/assets/logo.png`・`footer_icons.png` は既存ページ（P7）から切り出したもの。

生成した PNG を pptx に差し込む手順は、既存ページと同じ「1ページ＝全面画像」構成のため、
スライドを複製して画像リレーションを差し替えるだけでよい。
