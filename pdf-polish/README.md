# 五福パンフレット PDF ブラッシュアップ

スキャンされた2つのパンフレットPDF(グループホーム・デイサービスセンター 五福)の品質改善。

## 成果物
- `output/五福パンフレット(グループホーム・デイサービス)_改善版.pdf`(8ページ)
- `output/五福デイサービス_サービスの御案内_改善版.pdf`(4ページ)

## 処理内容
1. **画質改善**(`scripts/enhance.py` / 全12ページ)
   - 印刷網点のモアレ除去(デスクリーン)
   - 色ノイズ除去(輝度は維持しシャープさを保持)
   - レベル補正(紙の白を白に、黒を締める)+彩度復元
   - アンシャープマスクで文字・写真の輪郭を復元
   - スキャナー縁の影をトリミング
2. **地図の描き直し**(`scripts/map.py` → `master_map.png`)
   - 元の茶色背景・低コントラストの地図を、白背景の高コントラストな
     地図カードとして再作図(ランドマーク・鉄道・市電・河川・道路は元図踏襲)
   - 方位記号・凡例(市電/JR鹿児島本線/九州新幹線)・河川名を追加
3. **合成・再構築**(`scripts/composite.py`)
   - 両PDFの地図ページに新地図を配置、レイアウトのバランスを調整

## 再現手順
元スキャンの各ページJPEGを `orig/` に展開後:
```
python3 scripts/enhance.py     # → enh/ に補正済みページ
python3 scripts/composite.py   # 地図ページ2枚を合成
```
