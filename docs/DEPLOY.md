# Tobidai Cockpit をスマホから見られるように公開する手順

このドキュメントは、エンジニアでない方でも迷わず「社外(インターネット)からスマホでアクセスできる状態」まで
たどり着けるように書いています。使うサービスは **Vercel**(Webアプリを無料で公開できるサービス)です。

所要時間の目安: 15〜20分程度。

---

## 0. 事前に準備するもの

- GitHubアカウント(このアプリのリポジトリ `koboritobidai-gif/maiko` を持っているアカウント)のログイン情報
- Google スプレッドシート連携用の情報(すでに `docs/SETUP.md` の手順で準備済みの場合)
  - サービスアカウントの鍵JSONファイル
  - 連携中スプレッドシートのID
- 社内で共有する「合言葉」(公開後にアプリへアクセスする際のパスワード。好きな文字列でよい)

---

## 1. Vercelアカウントを作る(GitHubアカウントでログイン)

1. ブラウザで [https://vercel.com](https://vercel.com) を開きます。
2. 右上(またはトップページ中央)の **「Sign Up」** ボタンをクリックします。
3. ログイン方法の選択画面が出るので、**「Continue with GitHub」** をクリックします。
4. GitHubのログイン画面が出た場合は、GitHubアカウントのメールアドレス・パスワードを入力してログインします。
5. 「Vercelがあなたのアカウントにアクセスすることを許可しますか」という確認画面が出たら **「Authorize Vercel」** をクリックします。
6. 簡単なアンケート画面が出ることがありますが、内容は自由に選んで(または「Skip」で)進めて構いません。

これでVercelアカウントの作成は完了です。

---

## 2. リポジトリ(アプリ本体)をVercelに取り込む

1. Vercelの画面(ダッシュボード)右上あたりにある **「Add New...」** ボタンをクリックします。
2. メニューが開くので **「Project」** をクリックします。
3. 「Import Git Repository」という画面が表示されます。リポジトリの一覧の中から **`maiko`**
   (`koboritobidai-gif/maiko`)を探します。
   - もし一覧に出てこない場合は、「Adjust GitHub App Permissions」のようなリンクが表示されるので、
     クリックしてGitHub側の権限設定画面で `maiko` リポジトリへのアクセスを許可してください。
4. `maiko` の行にある **「Import」** ボタンをクリックします。

「Configure Project」という設定画面に進みます。この時点ではまだ **「Deploy」ボタンは押さないでください**。
次の3・4章の設定を先に行います(先にDeployしてしまっても後から直せますが、手順通りに進めるのが簡単です)。

---

## 3. 【重要】公開するブランチを正しく設定する

このアプリの本体は、GitHubの `main` ブランチではなく **`claude/shobidai-internal-system-kgflug`**
というブランチに入っています。何もしないとVercelは自動的に `main` を公開してしまい、
アプリが正しく表示されません。**必ず以下の設定を行ってください。**

### 3-1. 先にそのままDeployする

1. 「Configure Project」画面はそのまま(Root Directoryなどは変更不要)、
   一番下までスクロールして **「Deploy」** ボタンをクリックします。
2. ビルドが始まります(1〜2分程度)。この回は `main` ブランチが公開されるため、
   正しい画面が出なくても問題ありません。次の手順で公開ブランチを直します。

### 3-2. Production Branch(本番ブランチ)を変更する

1. Deployが終わったら、画面上部のプロジェクト名(`maiko`)をクリックし、プロジェクトのトップ画面に入ります。
2. 上部メニューの **「Settings」** タブをクリックします。
3. 左側のメニューから **「Git」** を選びます。
4. 「Production Branch」という項目があります。デフォルトでは `main` になっているので、
   入力欄をクリックして `main` を消し、以下のブランチ名を **正確に** 入力します。

   ```
   claude/shobidai-internal-system-kgflug
   ```

5. 入力欄の右側にある **「Save」** ボタンをクリックします。

### 3-3. 正しいブランチで再デプロイする

設定を変えただけでは、まだ古い(`main` の)公開内容のままです。以下の手順で
正しいブランチの内容を反映させます。

1. 上部メニューの **「Deployments」** タブをクリックします。
2. 一覧の一番上(最新のデプロイ)の右端にある **「…」(縦三点リーダー)** ボタンをクリックします。
3. メニューから **「Redeploy」** をクリックします。
4. 確認ダイアログが出るので、そのまま **「Redeploy」** ボタンをクリックします。
   - このとき「Use existing Build Cache」のチェックは外れていても入っていてもどちらでも構いません。
5. 1〜2分待つと、新しいデプロイが完了します(緑色の「Ready」表示になれば成功です)。

> 補足: この後に紹介する環境変数(4章)は、まだ設定していない状態でDeployしても構いません。
> 環境変数を保存した後にもう一度この「Redeploy」を行えば反映されます。

---

## 4. 環境変数(Environment Variables)を設定する

環境変数とは、アプリに渡す「設定値・秘密の情報」のことです。ソースコードには書かず、
Vercelの管理画面から安全に設定します。

1. プロジェクト画面上部の **「Settings」** タブをクリックします。
2. 左側のメニューから **「Environment Variables」** を選びます。
3. 「Key」(名前)と「Value」(値)の入力欄が表示されます。以下を1つずつ、
   Keyに変数名・Valueに値を入力して **「Save」**(または「Add」)を押す、を繰り返してください。
   特に指定がなければ「Environment」は Production / Preview / Development すべてにチェックが入ったままで構いません。

   | Key | Value | 補足 |
   |---|---|---|
   | `DATA_MODE` | `live` | 実際のスプレッドシート・Slackと連携するモードにする |
   | `GOOGLE_SERVICE_ACCOUNT_JSON` | ダウンロードした鍵JSONファイルの中身を**全部**貼り付け | 下記「4-1」参照 |
   | `SHEET_ID` | 連携中のスプレッドシートのID | `docs/SETUP.md` で控えた値 |
   | `APP_PASSWORD` | 社内で共有するパスワード(合言葉) | **必ず設定すること。下記「4-2」参照** |
   | `ANTHROPIC_API_KEY` | (任意)Claude APIキー | 設定しなくても動作する(未設定時はルールベース応答) |

### 4-1. `GOOGLE_SERVICE_ACCOUNT_JSON` の貼り付け方

- ローカルで動かすときは「service-account.json というファイルを置く」方式(`GOOGLE_SERVICE_ACCOUNT_FILE`)
  が使えましたが、**Vercelにはファイルをアップロードする仕組みが無いため、この方式は使えません。**
- 代わりに、ダウンロードした鍵JSONファイルをテキストエディタ(メモ帳など)で開き、
  中身(`{` から `}` まで全部)をそのままコピーして、Valueの入力欄に貼り付けてください。
- Vercelの入力欄は複数行の貼り付けに対応しているので、改行を消したり1行にまとめたりする必要はありません。
  コピーした内容をそのまま貼り付ければOKです。

### 4-2. `APP_PASSWORD` は必ず設定する

**`APP_PASSWORD` を設定しないと、公開後のURLは誰でも(全世界の誰からでも)アクセスできてしまいます。**
社内の数字を扱うアプリなので、必ず何らかのパスワードを設定してください。
ユーザー名は使わないので、ログイン時のユーザー名欄は空欄または何を入れても構いません。

### 4-3. 保存後は再デプロイが必要

環境変数を保存しただけでは、公開中のアプリにはまだ反映されません。
3-3章と同じ手順(「Deployments」タブ → 最新デプロイの「…」→「Redeploy」)を行ってください。

---

## 5. 公開されたURLをスマホで開く

1. プロジェクトのトップ画面、または「Deployments」タブの最新デプロイをクリックすると、
   `https://maiko-xxxxxxxx.vercel.app` のような形式のURLが表示されます(`xxxxxxxx` の部分は環境によって異なります)。
2. このURLをコピーし、スマホのメッセージアプリ(LINEなど)で自分に送るなどして、スマホのブラウザで開きます。
3. `APP_PASSWORD` を設定した場合、ブラウザから「ユーザー名とパスワードを入力してください」という
   認証ダイアログが表示されます。
   - **ユーザー名**: 空欄のままでよい(何か入力しても問題ありません)
   - **パスワード**: 4章で設定した `APP_PASSWORD` の値を入力
4. 正しく入力すると、アプリの画面が表示されます。

---

## 6. スマホのホーム画面にアイコンを追加する

毎回ブラウザでURLを入力しなくて済むように、ホーム画面にアイコンを追加しておくと便利です。

### iPhone(Safari)の場合

1. 上記URLをSafariで開いた状態で、画面下部(または上部)の **共有ボタン**(四角から矢印が上に伸びるアイコン)をタップします。
2. メニューを下にスクロールし、**「ホーム画面に追加」** をタップします。
3. 表示される名前(例: 「maiko」)を確認・編集し、右上の **「追加」** をタップします。
4. ホーム画面にアイコンが追加されます。

### Android(Chrome)の場合

1. 上記URLをChromeで開いた状態で、右上の **メニュー(縦三点リーダー)** をタップします。
2. メニューの中から **「ホーム画面に追加」**(機種により「アプリをインストール」)をタップします。
3. 表示される名前を確認し、**「追加」** をタップします。
4. ホーム画面にアイコンが追加されます。

---

## 7. トラブルが起きたときの見方

### 画面が真っ白・エラーが出る場合

1. Vercelのプロジェクト画面 → 上部メニューの **「Deployments」** タブを開きます。
2. 一覧の一番上(最新)のデプロイをクリックします。
3. 表示されたログ画面で、赤字のエラーメッセージがないか確認します。
   - 環境変数のスペルミス(`GOOGLE_SERVICE_ACCOUNT_JSON` などの名前間違い)や、
     JSONの貼り付け漏れが原因であることが多いです。4章を見直してください。

### 認証ダイアログが出ない・パスワードが違うと言われる場合

- `APP_PASSWORD` の設定内容(4章)を確認し、保存後に **必ず「Redeploy」を行ったか** を確認してください。
  環境変数は保存しただけでは反映されず、再デプロイが必要です。

### スプレッドシートの数字が反映されない場合

- ダッシュボードのデータは **約1分(60秒)ごと** に自動更新されます。
  シートを更新した直後は反映されていなくても、1分ほど待ってから画面を再読み込みしてください。
- それでも反映されない場合は、`docs/SETUP.md` の手順(サービスアカウントへのシート共有設定など)に
  抜けがないか確認してください。

---

以上で公開作業は完了です。何か分からない点があれば、Vercelの「Deployments」タブのログを
スクリーンショットで共有してもらえると調査しやすくなります。
