# 買った人が「安心する／参考になる」情報チェックリスト

月次レポートに何を載せるかの判断基準は **「オーナーが不安になる瞬間に、先回りして答えているか」**。
購入後のオーナーの不安は、だいたい次の5つに集約されます。

1. 本当に建っているのか（進捗不安）
2. 予定どおり引き渡されるのか（遅延不安）
3. 資産価値は上がっているのか（価格不安）
4. 貸せるのか・売れるのか（出口不安）
5. 手続き・税金は大丈夫か（実務不安）

以下は、それぞれに効く掲載項目です。★は優先度（★★★＝毎号必須）。

---

## 1. 進捗不安に効く

| 項目 | 優先 | ポイント |
|---|---|---|
| 定点観測写真（毎号 同アングル・同順番） | ★★★ | 最も効く。前月との2枚並べで「動いている」が一目でわかる |
| 撮影日をキャプションに明記 | ★★★ | 「使い回しの写真では？」という疑念を消す |
| 工程表（計画 vs 実績）のガントチャート | ★★★ | 進捗率の数字より説得力がある |
| 進捗率の**算定根拠**を明記 | ★★★ | 出来高ベースか工程消化率か。定義がブレると不信につながる |
| ドローン空撮・タイムラプス動画（QRコード） | ★★ | 街区全体の変化が伝わる。紙面はQRで動画へ誘導 |
| 現場人員・資材搬入の写真 | ★★ | 「実際に人と物が動いている」証拠 |
| 現地監理者の顔写真＋コメント | ★★ | 発信者の顔が見えると信頼度が上がる |

## 2. 遅延不安に効く

| 項目 | 優先 | ポイント |
|---|---|---|
| 引渡予定日と「前月からの変更有無」 | ★★★ | 変更なしでも毎号書く。書き続けることが信頼になる |
| 遅延が出た場合の日数・理由・回復見込み | ★★★ | **悪いニュースこそ先に書く。** 隠すと後で一気に信頼を失う |
| 遅延時の契約上の取り扱い（違約金・補償条項） | ★★ | 契約書のどこに書いてあるかの参照だけでも安心材料 |
| デベロッパーの状況（他プロジェクトの竣工実績、財務ニュース） | ★★ | 「この会社は大丈夫か」への回答 |

## 3. 価格不安に効く

| 項目 | 優先 | ポイント |
|---|---|---|
| 同エリアの新築㎡単価の推移（3か月前・前年同月比） | ★★★ | 自分の買値と比較できる形で |
| 中古の**成約**事例（募集価格ではなく成約） | ★★ | 実際に売れている価格が最も参考になる |
| 為替（USD/JPY・UZS/USD）と円換算の評価額 | ★★★ | 日本人オーナーは最終的に円で考える。購入時レートとの比較を必ず |
| 周辺の競合プロジェクト・新規供給量 | ★★ | 供給過剰リスクを自分で判断する材料 |
| 販売済率（同プロジェクト内） | ★★ | 完売に近いほど安心。数字が悪い月も出す |

## 4. 出口不安（貸せる／売れる）に効く

| 項目 | 優先 | ポイント |
|---|---|---|
| 近隣の募集賃料・成約賃料・稼働率 | ★★★ | 「いくらで貸せるか」が最大の関心事 |
| 想定利回り（表面／実質、**参考値である旨を明記**） | ★★★ | 保証と受け取られる表現は避ける |
| 賃貸需要の背景（周辺の企業進出、大学、駐在需要） | ★★ | 数字の裏づけになるストーリー |
| 転売可能になる時期・名義変更の手続きと費用 | ★★ | 意外と説明されておらず、不安が溜まりやすい |
| 竣工後の賃貸管理サービス・家具パッケージの内容と費用 | ★★ | 「貸すまでの段取り」が見えると安心 |
| 管理費・光熱費・修繕積立の目安 | ★★ | ランニングコストの実額 |

## 5. 実務不安に効く

| 項目 | 優先 | ポイント |
|---|---|---|
| そのオーナー個別の支払スケジュール・残額 | ★★★ | 個別差し込みができると満足度が跳ね上がる |
| 引渡しまでの全体フローと「現在地」 | ★★★ | 図で示す。今どの段階かが常にわかる |
| 登記・所有権証明の手続きと必要書類 | ★★ | 外国人所有まわりは特に不安が大きい |
| 送金ルート・手数料・所要日数の実務 | ★★ | 実際にやってみると詰まりやすいポイント |
| 税務（ウズベク側：固定資産税・賃貸所得税／日本側：確定申告、外国税額控除、国外財産調書） | ★★ | 年1回の特集号でも可。ただし年内に必ず1回 |
| ビザ・居住許可の最新情報 | ★ | 該当者向け |
| 用語集（現地語・不動産用語） | ★ | 巻末に固定で置く |

---

## レポート全体の設計ルール

- **毎号 同じ構成・同じ順番・同じ指標**にする。比較できることが安心の正体。
- **数字には必ず出典**（政府発表／デベロッパー公式／現地報道／自社試算）を添える。
- **悪い情報を必ず1つ以上載せる。** 良い話だけのレポートは、かえって信用されない。
- 利回り・値上がりについて**断定的表現や保証と読める表現は使わない**（誇大広告リスク）。
- 免責事項を毎号巻末に固定掲載する。
- 1ページ＝1テーマ。文字は詰め込みすぎず、写真と表を主役にする。
- オーナー限定感を出す（「オーナー様専用」の表記、専用窓口、オーナー数・国籍構成の共有）。
