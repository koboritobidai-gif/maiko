# スプレッドシート テンプレート仕様(Google Sheets 連携)

`DATA_MODE=live` の場合、`src/lib/adapters/spreadsheet.ts` の `GoogleSheetsSource` が
1つのスプレッドシート内の以下6タブを Google Sheets Values API(`batchGet`)で読み取ります(加えて、
任意タブ「送客単価」があれば別リクエストで読み取ります。下記参照)。
このページの表をそのまま新規スプレッドシートにコピペすれば動作します。

拠点(支店)の概念は無く、担当者個人単位で運用します。KPIは**週次入力**(毎週月曜に前週分を入力)、
月次で自動集計されます。

## 共通ルール

- **1行目はヘッダー行**(見出し文字列は任意。読み取りは列の位置=A列・B列…で行うため、見出し文言自体は
  パースに影響しません。分かりやすい見出しを付けてください)。
- **2行目以降がデータ行**。すべての列が空欄の行は自動でスキップされます(区切り用の空行があってもOK)。
- **日付列(週開始日/更新日/成約日/期日)は `YYYY-MM-DD` のプレーンテキストで入力してください**
  (例: `2026-07-20`)。Google スプレッドシートが自動で「日付」型に変換してしまうと
  意図しない値になることがあるため、該当列はあらかじめ「書式なし テキスト」に設定するか、
  入力時に先頭にアポストロフィ(`'2026-07-20`)を付けて文字列として入力することを推奨します。
- **金額は「万円」単位の数値**で入力してください(円換算はアプリ側で自動的に行います)。カンマ区切り
  (`1,234`)も読み取れますが、数値のみのシンプルな入力を推奨します。
- シートのタブ名・列の並び順は変更しないでください(変更するとパースエラーになり、
  自動的にデモデータへフォールバックします)。

## タブ「設定」

| A列(項目) | B列(値) |
|---|---|
| 手数料率 | 0.35 |

- 「手数料率」の行が必須です(0より大きく1以下の数値)。成約(求職者個別の入社確定)の手数料自動計算に使用します。
- 他の項目行を追加しても無視されます(将来の設定項目追加用に自由に使えます)。

  `新規登録` / `面談` / `企業提案` / `面接` / `内定` / `承諾` / `入社` / `辞退`
  (`新規登録`〜`入社` がパイプライン、`辞退` は離脱扱いでパイプライン集計から除外されます)。

  追加できます。

  - J列(年齢): 数値。空欄可(空欄や数値に変換できない値は無視され、年齢非表示として扱われます)。
  - K列(流入経路): 自由記述(例: `LINE広告` / `Instagram` / `紹介` / `求人媒体` / `KANOA紹介` など送客パートナー名)。
  - L列(送客先): 自由記述(紹介先企業名)。
  - M列(面接結果): 自由記述(例: `1次通過` / `最終待ち` / `内定`)。
  - N列(登録日): `YYYY-MM-DD`。空欄可。
  - O列(面談日): `YYYY-MM-DD`。空欄可。送客パートナーは**面談実施で課金**のため、費用集計の
    「どの月の費用か」の判定に最優先で使用します(空欄の場合は「登録日」→「更新日」の順で近似します)。
    また、ステージが「辞退」でも面談日が入っていれば「面談まで実施した(=課金対象)」として数えます。
  - **既存の行・既存のシートはそのままでOKです。** これらの列は無くても・空欄でもエラーになりません
    (I〜O列を追加していない8列のシートも引き続き問題なく読み取れます)。列を追加する場合は、既存の
    A〜H列の後ろ(I列以降)に追加するだけで反映されます。

  アプリ側の自動計算のため、シートには入力しません。

## タブ「送客単価」(任意)

成果報酬型の送客パートナー(1人登録・面談ごとに費用が発生する紹介元)の単価マスタです。**このタブ自体が
任意**で、無くても・読み取りに失敗してもエラーにはならず、アプリ組み込みの既定単価
(KANOA 27,500円 / マホガニー 22,000円 / foresma 27,500円 / 2peace(Tさん) 22,000円)にフォールバックします
(デモデータも同じ既定値を使用します)。

| A列(経路名) | B列(1人あたり単価・円) |
|---|---|
| KANOA | 27500 |
| マホガニー | 22000 |
| foresma | 27500 |
| 2peace(Tさん) | 22000 |

- 「経路名」は求職者タブ「流入経路」列との**部分一致**(trim・大文字小文字無視)で判定されます。
  例えば流入経路に `KANOA紹介` と入力されていても `KANOA` の単価が適用されます。
- 送客パートナーは**面談実施で課金**です。費用の対象人数は、流入経路が一致し、かつ面談を実施した求職者
  (ステージが「面談」以降、または「辞退」でも求職者タブの「面談日」が入っている人)です。
  面談前に辞退した人は対象外です。月の帰属は「面談日」(無ければ「登録日」→「更新日」)で判定します。
- 経路を追加・削除すればダッシュボードの表示・AI応答にもそのまま反映されます(単価マスタの並び順で表示)。

## 入力規則の推奨(Google スプレッドシート側)

シートの「データ」→「データの入力規則」で以下を設定しておくと、値のブレを防げます。

- メンバー「役割」列: リストから選択(`代表`, `CA`, `RA`)
- 求職者「ステージ」列: リストから選択(`新規登録`, `面談`, `企業提案`, `面接`, `内定`, `承諾`, `入社`, `辞退`)
- プロジェクト「状態」列: リストから選択(`順調`, `注意`, `遅延`)
- 週次KPI「区分」列: リストから選択(`求職者`, `法人`)
- 週次KPI「項目」列: リストから選択(上記の項目名一覧。区分ごとに別々の入力規則にすると入力ミスを防げます)
- 日付列(週開始日/更新日/成約日/期日): 「書式なしテキスト」に設定し、`YYYY-MM-DD` で統一入力

## サービスアカウントへの共有

シートを準備したら、サービスアカウントのメールアドレス(`xxx@xxx.iam.gserviceaccount.com`)を
「共有」設定に**閲覧者**権限で追加してください。手順は `docs/SETUP.md` を参照してください。
