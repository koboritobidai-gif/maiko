結論

  • 参入の方向性は正しい。高単価×急成長×候補者供給不足という、人材紹介にとって理想的な市場構造。
  • ただし営業ターゲットの見立てに1点修正が必要。「AIに疎い社長」はFDEの採用主ではなく、FDEが派遣される先（導入企業）。フィーを払う顧客は、AIプロダクトを売る側の企業（AIスタートアップ・SaaS・大手SIer）であり、彼らはAIに精通している。営業戦略はここに合わせて再設計する（→第4章・第6章）。
  • 勝ち筋は「候補者の目利きと供給」。求人は増えているが「FDEが務まる人材」の見極めが難しく、企業側も選考基準が固まっていない。SES・コンサル・PdM出身者を「FDE候補」として発掘・翻訳できるエージェントには大きな価値がある。

2. 市場環境：FDEとは何か、なぜ今か

2-1. FDEの定義

FDE（Forward Deployed Engineer）は、自社AIプロダクトを持つ企業に所属し、顧客の現場に常駐・半常駐して要件定義、カスタム実装（LLM連携、RAG構築、AIエージェント開発等）、業務への定着までを担うエンジニアです。「エンジニア×コンサル×カスタマーサクセス」のハイブリッド職で、データ分析企業Palantirが発祥です。

2-2. なぜ需要が爆発しているのか

  • AI導入の失敗はモデルではなく「導入」で起きる。MIT NANDAの調査では企業のAIパイロットの95%が損益に結びついておらず、その大半が導入・定着プロセスの失敗に起因。各社が「現場に入って動かし切る人材」を求め始めた。
  • 大手が職種として制度化。OpenAIはFDE専業の別会社「The Deployment Company」を設立（2026年5月）、AnthropicはBlackstone・Goldman Sachsと15億ドルのJVで金融顧客へのFDE常駐を開始。Salesforceは約1,000名のFDE体制を目標に掲げる。アクセンチュアもMicrosoftと共同でFDE専門組織を2026年に始動。
  • 日本でも1年でゼロから立ち上がった。国内公開求人は1年前のほぼゼロから急増中。FDE特化求人サイト「FDE Jobs」には既に70件超が掲載。

当社の勝ち筋：「FDE翻訳者」ポジション

この市場のボトルネックは求人でも候補者の絶対数でもなく、両者のマッチング精度です。

  • 企業側の悩み：「FDEを採りたいが、どんな経歴の人が務まるのか分からない。JDの書き方も選考方法も手探り」
  • 候補者側の悩み：「FDEという職種を知らない／自分がなれると思っていない／年収が跳ねることを知らない」

両者の間に立ち、「あなたの会社に必要なFDE像はこうです」「あなたの経歴はFDEとしてこう売れます」と翻訳できるエージェントになることが、単なる求人横流しとの決定的な差別化になります。これは営業トークではなく、実際にJD設計支援・選考設計支援・キャリア転換支援という具体的サービスに落とせます（→第4章）。

4. 具体的アクション：90日立ち上げプラン

Phase 10〜30日：市場の解像度を上げ、商品を作る

  • 求人の全数調査：Indeed・Findy・FDE Jobs・各社採用ページから国内FDE求人（類似タイトル含む）を全件リスト化。※米国データでは同一職務が6種類以上のタイトルで募集されており、「FDE」の文字列検索だけでは市場の約1/3を取りこぼす。「AIソリューションエンジニア」「AI導入コンサルタント」「デプロイメントストラテジスト」等も含めて捕捉する。
  • 採用企業10社にヒアリング：「なぜFDEが必要か」「どんな経歴なら通るか」「選考で何を見るか」を直接聞く。この一次情報自体が営業資産になる。
  • FDE適性の「翻訳表」を作る：SES出身・受託PM出身・コンサル出身・PdM出身・カスタマーサクセス出身それぞれについて「FDE求人にどう刺さるか」のレジュメ変換テンプレートを整備。
  • 候補者ペルソナの確定：第一ターゲットは「顧客折衝経験のある開発経験2年以上のエンジニア（現年収500〜800万円）」。年収が1.5〜2倍になる訴求が最も刺さる層。

Phase 231〜60日：候補者プールを作る

  • コンテンツで集める：「FDEとは？年収と転職ロードマップ」記事・診断コンテンツ（「あなたのFDE適性診断」）を公開し、検索・SNS経由で登録を獲得。FDEはまだ検索ボリュームが小さく、良質な日本語コンテンツが少ないため上位表示を狙いやすい。
  • スカウトで攻める：ビズリーチ・LinkedIn・Findy等で「SES/受託でAI案件経験あり×顧客折衝あり」の条件で直接スカウト。「FDEという選択肢をご存知ですか」という切り口は開封率が高い（本人が知らない高年収職種の提示）。
  • ミニ勉強会の開催：「FDEキャリア入門」ウェビナーを月1回開催。現役FDE（成約者や知人）を1人ゲストに呼べれば信頼性が跳ねる。

Phase 361〜90日：企業開拓と初成約

  • 最有望セグメントから攻める：国内AIスタートアップ（LayerX、JDSC、Gen-AX、テイラー等）と、FDE組織を立ち上げ中のSIer。「FDE候補者を◯名プールしています」という具体的な玉付き営業が最強。
  • 採用支援パッケージで差別化：単なる紹介ではなく「FDEのJD設計＋選考基準設計＋候補者紹介」のセットで提案。要件が固まっていない企業ほど喜ばれ、他社エージェントを排除できる。
  • 準FDE求人も扱う：純粋なFDE求人だけでは初期は数が足りない。AI導入コンサル、AIソリューションアーキテクト等の隣接求人も扱い、キャッシュフローを作りながらFDE特化ブランドを育てる。
  • 初成約の実績化：最初の1〜2件は手数料率を下げてでも決め、事例（企業インタビュー・候補者インタビュー）としてコンテンツ化する。

※隣接職種（AI導入コンサル等）の成約を含む。専任1〜2名体制を想定。ITエンジニア紹介の一般的な成約ペース（コンサルタント1人あたり月0.5〜1件）に対し、立ち上げ期の学習コストを織り込んで保守的に設定。

ユニットエコノミクスが良い理由

  • 1件あたり単価が通常のIT紹介の1.5〜2倍。同じ工数でも売上が跳ねる。
  • 候補者のリピート・リファラルが期待できる。FDEコミュニティは狭く、良い転職体験は横に伝播する。
  • 企業側もリピートする。FDEは1名では済まない職種（チームで増員していく）。1社開拓すれば複数成約が見込める。Salesforceの「1,000名体制」構想が象徴的。

6. 課題とリスク（正直な評価）

【最重要】当初仮説の修正：「AIに疎い社長に提案しやすい」は営業戦略として成立しない

FDEを雇用して給料を払うのは、AIプロダクトを「売る側」の企業（AIスタートアップ、SaaS、SIer）です。彼らの経営者・採用責任者はAIに精通しており、専門性の低い提案は一発で見抜かれるリスクがあります。一方、「AIに疎い社長」の会社はFDEが常駐しにいく先（導入企業）であり、FDE求人を出す側ではありません。

ただし、この着眼は捨てなくてよい。形を変えれば活きます：①導入企業側の「AI人材の社内窓口（AI推進担当）」採用支援という商品にする、②「AIに疎い経営者向けAI人材セミナー」を開き、そこから採用ニーズを拾う。つまり「疎い社長」はFDE紹介の顧客ではなく、隣接商品の顧客と再定義します。

課題・リスク深刻度対策
①候補者供給の細さ。「FDE経験者」はほぼ市場に存在しない高経験者ではなく「転換候補」を売る前提で設計。翻訳表（4章）とキャリア面談で候補者を作り出す
②目利きの難易度。技術と対人の両方を評価する必要があり、ミスマッチ時の返金リスクが高い高採用企業ヒアリングで選考基準を先に学ぶ。技術顧問（現役エンジニア）を1名確保し、レジュメ・スキルの一次スクリーニングを依頼
③外資トップ企業はエージェントを使わない傾向。最高単価ゾーンに入れない可能性中初期は国内スタートアップ・SIerに集中。外資は候補者側の実績を積んでから接点を作る
④職種名の揺れ。「FDE」表記の求人だけ追うと市場の1/3を逃す中類似タイトル（AIソリューションエンジニア等）を含む捕捉リストを運用（4章 Phase1）
⑤競合の参入。Findy・ムービン・renue・FDE Jobs等が既にコンテンツを展開中大手は「特化」しきれない。特化ブランド＋採用支援パッケージ＋90日でのスピード立ち上げで先行
⑥ブームの反動。「FDE」という名称自体が数年で別の名称に置き換わる可能性低〜中本質は「AI導入・定着人材」の紹介。名称に依存しない候補者プールと企業リレーションを資産化する
⑦社内リソース。既存事業と兼務では立ち上がらない中最低1名の専任＋技術理解のあるメンバーのサポート体制を確保する

Go / No-Go の判断基準（90日後）

  • FDE候補者プール：50名以上（面談済み・転職意向あり）
  • 取引企業（求人票保有）：8社以上
  • 成約：1件以上（または最終面接進行中3件以上）

これを満たせば専任増員して本格化、未達なら隣接職種（AI人材全般）への軸足移動を判断します。
